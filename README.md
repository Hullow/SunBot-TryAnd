# SunBot-TryAnd
SunBot: A robot that picks up miniature solar panels, places them into mounting frames, and confirms when each panel is correctly positioned on floor markings

## Equipment
- Robot: *LeKiwi*, a 3-wheeled robot + gripper mounted on top. Two cameras: one on the gripper's wrist, and the other on the wheeled base
